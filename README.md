# PDF Text Editor

Your personal PDF text editor. Open a PDF, click any text to change it, pick a font and weight if you like, then download the edited PDF. Everything runs in your browser.

## Files

All files sit together in one folder, with no subfolders:
- `index.html` is the whole app.
- `*.ttf` files are the fonts it uses to match Calibri, Cambria, Arial, Times and Courier automatically.
- `*.fontpack` files hold the fonts in the font menu, one file per font family.

## Updating your GitHub site

1. On your repository, click **Add file → Upload files**.
2. Drag in every file from this folder (49 files) and click **Commit changes**. Files with the same name are replaced.
3. Wait 1 to 2 minutes, then open your site and press Ctrl+Shift+R.

## Font menu

Click any text, then use the menu on the toolbar:
- **Font:** "Original (match PDF)" or any of the Google Docs fonts.
- **Weight:** Thin, Light, Regular, Medium, Semi Bold, Bold, Extra Bold, Black, depending on what the font offers.
- **I:** italic on or off.

Arial, Calibri, Courier New, Georgia and Times New Roman are Microsoft fonts that can't be shared freely, so the menu uses free fonts with the same letter widths (Arimo, Carlito, Cousine, Gelasio, Tinos). Comic Sans MS, Impact, Trebuchet MS and Verdana use close look-alikes (Comic Neue, Anton, Fira Sans, DejaVu Sans). All included fonts are free to use (SIL Open Font License, Apache, or similar).

The menu fonts cover English and Western European letters (for example é, ü, ñ, ł).

## Your saved work

Edits save automatically in your browser. Use **Export backup** now and then, and **Restore backup** to move work to another device.
